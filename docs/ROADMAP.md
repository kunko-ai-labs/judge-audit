# Roadmap

What shipped, what is next, and why. Issues on GitHub are the live backlog; this file is the narrative.

| Version | What | Why |
|---|---|---|
| v0.1 (done) | Harness: pluggable `Judge`, shadow-mode runner, ECE + reliability bins + accuracy-coverage + zero-error coverage, cost and p50/p99, Markdown/HTML reports, `check` CI gate, simulated judge | The questions a buyer asks before automating, answerable without trusting the vendor |
| v0.2 (done) | **Independent audits of a vendor judge** (Jev via the AI Gateway evaluate API): clean emails, adversarial emails, task routing + the option-description ablation; raw checkpoints committed; provenance in every report; `verify_published.py` in CI; **`llm` adapter** (Claude via SDK, any OpenAI-compatible endpoint) and **Jev-compatible endpoints** (OpenJev) through `JEV_ENDPOINT`; Apache-2.0, tests, CI | A number without its evidence is an opinion. The repo goes public with every claim reproducible, and with the adapters people need to audit what they actually run |
| v0.3 (done) | **MCP server** (`judge-audit-mcp`: `run_audit`, `check_drift`, `list_judges`) so agents and IDEs audit a judge in place; **GitHub Action** (`mode: run \| check`, sticky PR comment with the audit table, self-demo workflow) for the Marketplace; launch video | Distribution: the audit has to live where the judge is used — the agent session and the pull request |
| v0.3.x | **Side-by-side** (#21): Jev vs local open models (Ollama) vs Gemini / Claude on the four datasets, checkpoints committed, `docs/arena-2026-09.md` | A side-by-side on the same data and harness is what a buyer asks for |
| v0.3.x | **Consensus audit** (#39): the Arena judges as a jury — is vote share a confidence score? — plus a pre-registered deliberation round (Shao 2026, Huang et al. 2026) | An agent jury often treats agreement as evidence; a calibration audit is where that assumption gets tested |
| v0.4 (done) | **Fine-tuned classifier baseline on a pre-registered held-out split** (#53); **intervals on every published number**, exact where the bootstrap degenerates (#59); release hardening: escaped PR comment, no home paths in committed files (#58) | "Isn't a judgment model just a classifier?" deserved a measured answer, and a repository about calibration cannot publish a zero-width interval |
| v0.4 (done, 2026-09-26) | **The instrument, corrected and auditable**: order-independent zero-error coverage; a drift gate that refuses incompatible baselines; an injection-free Action; unknown confidence never imputed; no decision leaves the denominator silently; Brier, equal-mass ECE and NLL (never clipped) next to the ECE; type-7 latency percentiles with the slowest call; the served model version recorded; every README table figure checked in CI; the headline repeated three times under pre-registration and checked on distinct texts (#85) | The 22-Sep audit: the claims had run ahead of the instrument, and a buyer needs numbers that survive a hostile recomputation |
| v0.5 | **A benchmark on real data** (#94): human-labelled public datasets, ≥ 1,000 rows per task, a hidden held-out slice (#86); v2 stress sets without duplicate texts (#87); current models including OpenAI's (#88); confidence measured three ways — verbalized, token log-probability, self-consistency (#89); repeats for every judge (#90); a power analysis and pre-registration (#91); prompt sensitivity (#92); literature and the other public Jev audits (#93); MCE, the worst bin (#12) | v0.4's evidence is synthetic, small and single-domain, and compares a probability with a verbalized number; a benchmark must not |
| v0.6 | **Public leaderboard** (#14, #15) with a submission spec, and the **AI Act evidence pack** (#10, #11, #13): decision receipts, a dossier *adapted* to the logging, oversight and accuracy articles — never "certified" | Leaderboards are distribution; a European buyer's compliance team needs the dossier |
| later | Production drift monitor; Spanish-language audit packs for regulated sectors; conformal-prediction coverage guarantees (research) | Recurring revenue and the ES/EU wedge |

Out of scope: building a judge. judge-audit checks judges; it does not compete with them.
